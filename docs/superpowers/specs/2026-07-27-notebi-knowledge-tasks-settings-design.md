# NoteBi 知识库、合集、任务中心与设置闭环设计

**日期：** 2026-07-27  
**状态：** 已完成分段产品确认，等待汇总文档复核  
**基线：** `feat/r7-fix-forward` at `94edb9a`  
**范围：** 统一日志、网络与下载、知识库、合集、任务中心与批量任务

## 1. 背景

R7 已恢复知识库入口、收藏夹与媒体深链接等主流程，但当前仍存在五类结构性问题：

1. 监控页把任务活动与应用日志分成两套视图，应用日志仅保存在内存，重启即丢失，新启动时通常为空。
2. 网络页与下载页重复展示代理、Cookie、PO Token、Visitor Data；部分网络页字段只写入浏览器本地状态，未被后端下载流程消费。
3. 知识库已经支持单次 AI 回答和来源卡片，但缺少连续追问、范围快照、可靠的多合集召回和完整的来源预览。
4. 合集列表和详情存在冗余入口、占位面板和布局膨胀；融合笔记、独立副本与批量任务尚未形成清晰的一等模型。
5. 右下角任务浮层、按合集批量处理页和拟新增的批量任务中心可能形成三套互相重复的任务体验。

本设计选择“统一闭环”路线：

`网络与下载提供能力 → 合集组织内容 → 知识库回答并引用 → 任务中心管理执行 → 标准日志解释过程`

## 2. 已确认的产品决策

1. 合集页不保留独立 AI 聊天；“问这个合集”进入统一知识库，并自动限定当前合集。
2. 知识库支持一个、多个或全部合集，支持连续追问。
3. 每轮回答重新检索并生成独立来源，不能沿用上一轮引用。
4. 视频和音频来源可跳转到对应时间，等待媒体就绪后定位并尝试自动播放。
5. 监控页只保留一条标准日志，合并任务事件和应用日志。
6. 标准日志本地保留 7 天，最多 50 MB。
7. 网络页负责全局联网与智能分流；下载页负责下载专用配置。
8. 国内来源默认直连，YouTube、Tavily及海外模型默认使用全局代理。
9. PO Token 与 Visitor Data 从界面和新任务链路移除。
10. Cookie 默认从本机浏览器读取，`cookies.txt` 仅作备用。
11. 删除合集默认不删除内容；可选将内容移入垃圾桶。
12. 左侧导航新增长期可见的“任务中心”。
13. 右下角任务浮层保留，但只显示活跃和需处理摘要。
14. 同一内容复制到其他合集后成为独立副本，以 `lineage_id` 关联，不自动合并或覆盖。

## 3. 设计原则

### 3.1 单一事实来源

- 网络、下载、日志保留策略和任务状态以后端本地持久化为准。
- 前端 store 只缓存服务器状态或保存未提交草稿，不能成为长期真相。
- 保存设置必须完成 `GET → 修改 → PUT/PATCH → GET 读回 → 实际消费者使用`。

### 3.2 一套任务执行引擎

- 批量任务只增加父级批次和调度能力。
- 每个子任务继续复用现有 pipeline，不复制下载、转写、分析、总结或索引实现。
- 右下角浮层、任务中心、合集批次标签和监控页读取同一批任务和事件。

### 3.3 回答必须可追溯

- AI 回答只允许引用本轮真实检索到的片段。
- 引用粒度是具体 chunk，不是合集或整篇文档。
- 回答、引用编号、来源卡片和媒体深链接必须一一对应。
- 证据不足时明确说明，不能以模型常识补齐本地材料中不存在的事实。

### 3.4 删除、取消和暂停语义分离

- 删除合集、删除批次记录、取消任务、暂停调度和移入垃圾桶是不同操作。
- 界面文案必须与后端动作一致。
- 任何已有成功结果都不能因删除批次记录或取消剩余任务而被静默删除。

## 4. 信息架构

左侧主导航调整为：

1. 新建
2. 首页
3. 笔记
4. 合集
5. 收藏夹
6. 知识库
7. 任务中心
8. 设置

新增或调整路由：

- `/knowledge`：统一知识库
- `/workspaces`：合集列表
- `/workspaces/:workspaceId`：合集详情
- `/tasks`：全局任务中心
- `/tasks/batches/:batchId`：批次详情
- `/processing/:taskId`：现有单项处理页
- `/settings/network`：联网与智能分流
- `/settings/download`：下载与保存
- `/settings/monitor`：运行状态与标准日志

旧 `/processing/batch/:workspaceId` 在兼容期内重定向到能够识别对应批次的页面；无法唯一识别时回到该合集的“批量任务”标签，而不是把合集本身继续当作批次。

## 5. 统一标准日志

### 5.1 事件模型

统一日志事件至少包含：

- `event_id`
- `timestamp`
- `level`
- `category`
- `message`
- `task_id`（可选）
- `batch_id`（可选）
- `workspace_id`（可选）
- `stage`（可选）
- `progress`（可选）
- `duration_ms`（可选）
- `retry_count`（可选）
- `details`（经过脱敏的可选结构）

分类包括：

- system
- task
- download
- transcription
- diarization
- vision
- model
- knowledge
- export

### 5.2 后端行为

- 使用本地滚动日志文件，而非仅使用进程内 deque。
- 默认保留 7 天，总容量上限 50 MB。
- 服务启动完成后立即写入启动事件，保证新安装不是空白页。
- 后端重启后继续读取现有日志。
- 提供按 `after_id` 增量拉取最新日志和按 `before_id` 向前分页的接口。
- 任务状态变化同时写入统一事件流。
- API Key、Cookie、代理密码、完整模型请求正文和敏感本地路径必须脱敏。

### 5.3 前端行为

- 移除“任务活动 / 应用日志”双标签。
- 初次进入加载最新 200 条，按时间正序展示并定位到底部。
- 自动跟随新日志；用户向上滚动后暂停跟随并显示“跳到最新”。
- 向上滚动加载更早记录。
- 支持级别、模块和关键词筛选。
- 支持通过 `task_id`、`batch_id` 或 `workspace_id` 深链接进入过滤结果。
- 保留“打开日志目录”和“导出诊断包”。
- 移除只清前端画面的“清空”操作。

## 6. 网络与下载设置

### 6.1 网络页职责

网络页管理：

- 连接模式：智能分流、全部直连、全部代理
- 全局代理
- 国内来源连通测试
- 海外来源连通测试
- Tavily 联网搜索配置与测试
- 最近一次检测状态和耗时

智能分流默认规则：

- B站、抖音、小红书：直连
- YouTube、Tavily及海外模型：使用全局代理
- 下载页可选择继承、强制直连或强制代理

代理支持 HTTP、HTTPS 和 SOCKS。包含用户名或密码时，只显示脱敏值，日志不得记录完整 URL。

### 6.2 下载页职责

下载页管理：

- 媒体存储根目录
- 文件名模板和实时预览
- Cookie 来源
- 下载并发
- 失败重试
- 连接超时
- 下载代理策略

媒体存储根目录只影响之后下载的文件；已有文件不自动搬迁。保存前检查目录存在性、可写性和剩余空间。各合集仍使用自己的子目录。

### 6.3 Cookie

默认匿名下载。需要登录、年龄验证或站点验证时再引导用户配置 Cookie。

首选方式：

- 选择 Chrome、Firefox 或 Safari
- 选择浏览器配置档案
- 本机按需读取
- 显示读取状态和最后检测时间

备用方式：

- 导入 Netscape 格式 `cookies.txt`
- 复制到 NoteBi 私有本地目录
- 限制文件权限

页面提供检测、重新读取和删除授权。Cookie 原文不展示、不上传、不进入日志或诊断包。

PO Token 与 Visitor Data：

- 从 UI 删除
- 新任务不再传入
- 旧字段兼容读取一个版本但不消费
- 后续独立迁移删除遗留字段

### 6.4 保存闭环

- 页面 mount 时读取后端配置。
- 测试按钮可以使用当前草稿，但不隐式保存。
- 保存后立即 GET 读回并比较。
- 恢复默认也写入后端并读回。
- 每页只保留一套保存与重置操作。
- 下载测试需要证明目录、代理、Cookie、并发、重试、超时和命名均到达真实下载消费者。

## 7. 知识库

### 7.1 页面结构

宽屏三栏：

- 左栏：对话历史
- 中栏：问题、回答和引用来源
- 右栏：当前来源预览

窄屏：

- 对话历史为抽屉
- 来源预览为底部面板

保留两种模式：

- AI 回答
- 原文检索

原文检索不调用生成模型。

### 7.2 对话和范围

每个对话保存：

- 标题
- 创建和更新时间
- 默认合集范围
- 消息列表

每条用户消息和回答保存当时的合集范围快照。范围可以是全部、单个或多个合集。修改范围只影响下一条问题。

支持：

- 新建
- 自动标题
- 重命名
- 删除
- 停止生成
- 重新生成并保留回答版本

### 7.3 检索

连续追问先根据必要的对话上下文形成独立检索问题，再执行本轮检索。

多合集检索：

1. 每个合集分别召回候选片段。
2. 合并候选。
3. 统一重排。
4. 在相关性允许的前提下保留来源多样性。
5. 不为满足“每个合集都有来源”而加入无关片段。

页面显示：

- 选择了哪些合集
- 已索引数量
- 索引中或失败的内容
- 本轮使用片段数
- 检索与生成耗时

### 7.4 回答和引用

- 关键结论使用 `[1]`、`[2]` 编号。
- 编号指向本轮具体片段。
- 被引用来源始终显示。
- 相关但未引用原文单独折叠。
- 每个引用保存 workspace、item、chunk、start/end 时间和片段快照。
- 删除原内容后保留历史片段快照，但来源入口标记为失效。
- 证据不足时输出明确的不足说明和最接近片段。

### 7.5 来源预览与深链接

右侧预览显示：

- 标题
- 所属合集
- 内容类型
- 原文片段和上下文
- 完整笔记入口
- 收藏操作
- 媒体预览

视频和音频：

- 等待播放器 handle 与 metadata 就绪
- 定位到 `start_ms`
- 尝试自动播放
- 被浏览器拒绝时停在正确时间并显示操作提示
- 同一参数只消费一次

文本和图文：

- 跳到段落或图片
- 短暂高亮
- 定位失效时回退到笔记顶部并提示

### 7.6 响应状态

依次显示：

`理解问题 → 检索合集 → 重排来源 → 生成回答`

答案可以流式显示，但引用只能在映射确定后出现。取消生成后保留已经检索到的来源。

## 8. 合集

### 8.1 合集列表

- 标题区固定为紧凑高度。
- 新建合集使用小型弹窗。
- 选择内容后使用 sticky 操作条，不撑高标题区。
- 删除文件夹、移动文件夹、整理和列表顶部标签输入。
- 删除合集类型筛选。
- 合集卡片展示简介、封面、内容构成、活跃任务、索引状态和更新时间。

新建合集只包含：

- 名称
- 简介
- 可选封面
- 可选标签

### 8.2 合集详情

顶部展示：

- 封面、名称、简介和标签
- 内容数量
- 融合笔记数量
- 活跃任务数量
- 索引状态

主要操作：

- 添加内容
- 批量导入
- 问这个合集
- 生成融合笔记
- 更多

标签页：

- 内容
- 融合笔记
- 批量任务

删除合集内重复聊天弹窗和未实现的风格占位面板。

### 8.3 独立副本

列表中的“加入合集”改名为“复制到合集”。

复制后：

- 生成新的 item
- 分配共同 `lineage_id`
- 内容可以独立编辑
- 显示其他合集中的相关副本
- 支持并排比较和打开另一版本
- 不自动覆盖、同步或合并

任何同步都必须明确选择来源版本、目标版本并预览差异。

### 8.4 融合笔记

融合笔记成为一等内容，保存：

- 标题
- 正文
- 来源 item 集合
- 引用
- 版本
- 创建与更新时间

支持基于全部或选中内容生成、编辑、重新生成新版本、比较和导出。来源更新后显示“来源已有更新”，由用户决定是否重建。

融合笔记可以进入知识库索引，但必须标记为二次整理内容。

### 8.5 删除

- 默认仅删除合集。
- 内容仍留在其他合集或进入未归类。
- 可选把合集中的内容移入垃圾桶。
- 不立即永久删除。

## 9. 任务中心与批量任务

### 9.1 入口与视图

新增 `/tasks`，提供：

- 批次
- 单项任务
- 失败项

统计处理中、等待中、已完成、需处理和已取消。支持按合集、来源、状态和时间筛选。

### 9.2 批量来源

支持：

- 多个链接
- 多个本地文件
- B站合集
- B站收藏夹
- UP 主投稿
- 视频分P
- YouTube 播放列表

创建流程：

`选择来源 → 解析预览 → 排除条目 → 处理重复/受限项 → 选择目标合集 → 设置统一笔记参数 → 提交`

笔记风格、说话人、画面分析、关键帧和补充要求常驻显示。

### 9.3 重复项

- 目标合集已存在：默认跳过。
- 其他合集存在：提示复制独立副本。
- 用户可选择跳过、复制已有笔记或重新处理。
- 重新处理必须显式选择。

### 9.4 批次模型

批次保存：

- `batch_id`
- 名称
- 来源类型和引用
- 目标合集
- 设置快照
- 子任务引用
- 聚合计数
- 创建、开始、完成时间
- 状态

子任务继续使用现有 pipeline。批次状态由子任务推导：

- 全部等待：QUEUED
- 任意运行：RUNNING
- 全部成功：COMPLETED
- 成功和失败并存：PARTIAL
- 全部失败：FAILED
- 用户取消：CANCELLED 或 PARTIAL_CANCELLED

### 9.5 调度、暂停和取消

- 批量提交不会同时启动全部子任务。
- 使用下载设置中的并发上限。
- 多批次公平轮转。
- 修改并发只影响后续调度。

暂停批次：

- 停止启动新任务
- 运行任务在安全阶段结束后暂停
- 恢复后继续

取消批次：

- 取消等待任务
- 请求运行任务停止
- 保留已经成功的内容和历史

当前浮层“暂停全部”实际取消任务的行为必须修正，不能只改文案。

### 9.6 重试

- 单项重试
- 批次全部失败项重试
- 只重试说话人
- 只重试摘要
- 从可复用阶段继续

重试记录为同一逻辑子任务的新 attempt，不重复创建内容。

### 9.7 浮层

- 单项任务独立显示。
- 同一批次默认聚合。
- 展开后显示活跃和失败子任务。
- 完成后退出浮层。
- 失败和部分完成保留到用户处理或隐藏。
- “查看全部”进入 `/tasks`。

### 9.8 批次详情

显示来源、目标合集、设置快照、总进度、计数和子任务列表。支持打开笔记、重试、暂停、恢复、取消和查看过滤日志。

删除批次记录不删除生成内容，运行中批次不能直接删除。

## 10. 安全与隐私

- 所有内容、对话、日志、Cookie 和任务数据默认保存在本机。
- Cookie 不上传、不回显、不进入日志。
- API Key 和代理密码在 UI 与日志中脱敏。
- 导出诊断包前再次执行结构化脱敏。
- 日志不得记录完整转写、完整提示词、完整模型请求正文或个人敏感路径。
- 浏览器 Cookie 读取失败必须给出权限说明，不尝试绕过系统权限。

## 11. 响应式和可访问性

- 低高度视口中标题区和批量操作区不挤走内容。
- 所有主页面在五个验收视口无横向溢出。
- 浮层可通过键盘打开、关闭和操作。
- 日志和任务状态不能只依赖颜色。
- 引用编号、来源卡和深链接具有明确无障碍名称。
- 对话抽屉、来源抽屉和批量创建弹层正确管理焦点。

## 12. 测试与验收边界

### 12.1 单元和契约测试

- 配置 GET/保存/读回/恢复默认/清除路径
- 智能分流与下载覆盖规则
- Cookie 读取、导入、删除和脱敏
- 日志持久化、滚动、分页和脱敏
- 批次状态聚合、重复项策略、暂停、取消和重试
- 对话范围快照、每轮重新检索和引用映射
- 独立副本 lineage 与不自动同步
- 合集删除不删除内容

### 12.2 集成测试

- 设置值进入真实下载消费者
- 下载任务写入统一日志
- 批次拆成现有 pipeline 子任务
- 任务中心和浮层读取一致状态
- 知识库按一个、多个和全部合集检索
- 回答引用指向实际 chunk
- 深链接定位媒体时间并处理 autoplay reject

### 12.3 浏览器验收

- 监控页默认定位最新记录，刷新和后端重启后日志仍存在
- 网络和下载测试给出可解释结果
- 新建合集和批量选择不撑高页面
- 批量创建一页可看到来源、预览、合集和常用笔记设置
- 任务浮层按批次聚合，完成项自动消失
- 任务中心能查看历史、失败和批次详情
- 知识库连续追问、范围切换、引用预览和媒体跳转通过
- 五个视口无横向溢出，console error 为 0

## 13. 实施边界

本设计应拆成五个可独立交付和回滚的子项目：

1. 标准日志
2. 网络与下载设置
3. 知识库对话与引用
4. 合集工作区
5. 任务中心与批量任务

共同基础类型应先以独立提交落地，但每个子项目必须有自己的测试、提交边界和验收证据。不得把无关 UI 重构、设计 token 清理或历史文件清理混入这些阶段。
