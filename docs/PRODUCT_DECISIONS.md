# NoteBi 已确认产品决策

本文件只记录用户已经确认、会影响实现边界的稳定决策。新想法在确认前不写入本文件。

## 产品范围

- 产品只保留 NoteBi，不恢复 Nibi / ReplicaBi 多产品模式。
- 删除并不再开发：复刻、AI 分镜、AI 导演、提示词格式、提示词版本、生成提示词和复刻包。
- 笔记不做音乐分析：删除 BPM、调性、风格、情绪、乐器、氛围、音乐分段、音乐教学和 Suno / Udio 提示词。
- 保留并继续完善：视频、图片、音频、文字笔记，画面理解、关键帧、OCR、描述、标签、转写、字幕、说话人、总结版本、知识库、搜索、问 AI 和正常导出。
- 旧 Replica 数据的启动期清理、旧创建意图和旧任务类型拒绝属于升级安全能力，暂时保留。

## 当前交互决策

- 任务浮窗只有在存在运行中任务时显示。
- 排队、失败和已完成状态不让浮窗常驻；完整状态在任务中心查看。
- 代理设置只保留在“网络设置”页。
- 下载设置页不再保存或展示第二份代理策略；下载与字幕请求实际只服从网络设置，旧 `download.proxy_mode` 仅兼容读取。

## 数据与设置

- NoteBi 本地优先；用户工作区、媒体、索引、设置和模型数据不得在普通项目清理中删除。
- 设置变更必须满足“保存成功、GET 读回一致、刷新后仍一致”。
- API 响应和日志不得暴露 API key、Cookie、Token、PO Token、Visitor Data 或本地 Cookie 目录。

## 平台顺序

- 当前先完成和完善全部产品功能。
- macOS/Linux 功能与验收收口后，再启动 Windows 实机适配。
- Windows 源码可见离线整合包属于后续独立阶段，不与当前功能开发混做。
