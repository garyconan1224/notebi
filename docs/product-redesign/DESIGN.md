# NoteBi 产品设计系统

版本：第二轮定点校准 · 2026-07-29

## 产品姿态

NoteBi 是本地优先的中文多媒体笔记软件：把视频、音频、图文和文本变成可编辑、可回看、可导出的结构化笔记。视觉目标是成熟、安静、证据感明确的生产力工具，不使用营销页结构、玻璃拟态、粉紫蓝渐变或过度胶囊。

持久笔记、运行中任务、任务诊断和总结派生物必须有清晰的数据边界。用户看到的是可审计的阶段状态和可编辑产物，不是不可验证的生成过程。

## Token 合同

实现事实源是 `frontend/src/styles/nibi-tokens.css`。业务代码只使用该文件提供的短名，不另建第二套表面、边框或强调色语义：

| 用途 | 短名 |
|---|---|
| 页面背景 / 次级背景 / 表面 | `--bg` / `--bgalt` / `--srf` |
| 主文字 / 次文字 / 弱文字 | `--fg` / `--fg2` / `--mut` |
| 普通边框 / 强边框 | `--bdr` / `--bdrs` |
| 强调 / 悬停 / 浅底 | `--acc` / `--acch` / `--accl` |
| 成功 / 警告 / 错误 | `--ok` / `--wrn` / `--err` |

排版、圆角、阴影和媒体覆盖层继续使用既有的 `--fd`、`--fb`、`--fm`、`--rs`、`--r`、`--rl`、`--rf`、`--sh1`、`--sh2`、`--sh3`、`--ov-player`、`--ov-ink`。

## 品牌与排版

- BrandMark 是深色笔记/N 图形加右上记录点；Lockup、favicon、Apple/maskable 和浏览器图标使用同一几何结构。
- 展示字体优先得意黑，正文使用系统无衬线，代码、时间码、路径和状态编号使用等宽字体。
- 页面标题约 32px，正文 14–16px，说明 12–13px。
- 中文文案说明真实状态，例如“已下载 38%”“等待中”“需要处理”，不使用无证据效率数字。

## 视觉层级

- 70–90% 面积由背景、表面、主文字和弱文字构成。
- 强调色只承担主操作和少量状态；成功、警告、错误使用各自语义色。
- 类型颜色不能成为唯一信息，必须同时有文字或图标。
- 卡片使用轻表面；浮层和悬停使用中阴影；模态和固定选择栏使用强阴影，不使用大面积发光。
- 基础间距 4px，组件间距 8/12/16px，区块间距 24/28/32px。

## 一级结构

一级入口固定为：首页、笔记、任务中心、合集、设置。

- `/`：工作区首页。
- `/notes`：持久笔记索引，读取 `/workspaces/library`。
- `/tasks`：批次默认任务中心。
- `/collections`：稳定一级合集实体。
- `/settings`：六组设置。
- `/workspaces/:workspaceId/items/:itemId/note`：统一笔记工作台。

旧结果页只保留兼容重定向。

## 首页与任务边界

首页最近笔记只读取持久 `/workspaces/library` 快照。运行任务是独立的紧凑活动层，不直接伪装成笔记。任务完成后按 `workspace_id + item_id` 去重；总结子任务只追加版本或派生视图，不能改变已有笔记的可读状态。

任务中心默认显示批次。四个统计卡固定为：进行中、已完成、需处理、等待中。基础过滤固定为：全部、进行中、已完成、异常；来源和日期进入高级筛选。

公开阶段固定为：

`准备 → 获取素材 → 下载 → 转写 → 区分说话人 → 画面理解 → 生成总结 → 保存笔记 → 完成`

普通页面只展示阶段摘要、进度、成功/失败/等待和时间。原始模块日志只在高级诊断中出现。

## 笔记、合集与导出

- `/notes` 顶栏只保留搜索、内容过滤、短排序和视图切换。
- 多选动作固定在底部。
- 合集选择器可搜索并分页或加载更多。
- 空、1 项、多项合集保持相同实体与一级路由。
- 合集移动/复制语义在产品决定前使用中性文案。

导出严格分两步：

1. 内容来源：当前显示、主笔记、具体总结、转写、原始素材。
2. 文件格式：MD、HTML、PDF、Word、长图、PPT、SRT、VTT、JSON、原始格式。

“整包导出”是独立第三动作。

## 笔记工作台

- 左侧统一媒体区、播放控件、高对比时间轴。
- 时间轴并列章节、说话人轨；视频补关键帧层，音频补波形层。
- 字幕显示时间码、说话人、文本和身份绑定入口。
- 右侧总结区包含版本、独立输出语言、真实富文本编辑器、保存状态和公开生成状态。
- “新总结”只保留一个入口，成功后在用户未切换版本时选中新版本。
- AI 工具提供思维导图、待办、要点卡、测验/闪卡、术语表和时间线，不重复新建总结。
- 问 AI 桌面为可调宽右侧上下文栏，小屏为底部抽屉。

## 设置与模型

设置固定六组：常规与外观、AI 与模型、分析与生成、导入与网络、笔记与数据、诊断与关于。

NoteBi 管理自己负责下载的 Faster Whisper、MLX Whisper、Sherpa、WeSpeaker、PaddleOCR。Pyannote 是许可高级回退。Ollama 等外部运行时只展示连接状态，不由 NoteBi 下载或删除。

模型状态覆盖：未下载、排队、下载中、暂停、校验中、已就绪、失败；卡片显示进度、空间、校验、激活和删除。

## 状态、无障碍与响应式

- 主要页面覆盖 loading、empty、error、success、running、paused、offline。
- 动效尊重 `prefers-reduced-motion`。
- 触控目标至少 44px；颜色不是唯一状态信号；控件使用真实 button、label、aria 和可见焦点。
- 检查 1440、1280、1024、768、390px，不允许横向滚动。
- 1024px 收窄侧栏，768px 进入堆叠布局，390px 优先标题、搜索、关键操作和正文。
