## 1. 目标

把 NoteBi 收敛为一套本地优先的多媒体笔记产品：

- 首页、笔记、任务和合集使用一致的数据语义；
- 设置、监控、模型管理和所有主页面遵循同一设计系统；
- 视频、音频、图片、文本统一进入 NoteShell；
- 总结、AI 工具、问 AI、导出、说话人和时间轴形成可验证闭环；
- 任务页面能解释当前阶段、产出预览和失败位置；
- 本地模型可查看、下载、验证、启用和安全移除；
- 全量自动测试、真实 API、浏览器交互和视觉检查通过后，合入本地 `main`。

## 2. 已确认约束

- 不恢复 Nibi / ReplicaBi、复刻、分镜、AI 导演或生成提示词。
- 不增加 BPM、调性、风格、情绪、乐器、音乐分段或 Suno / Udio。
- 不恢复合集“风格报告”。
- 不做 Windows、安装包或整合包。
- 不增加云账号、多用户协作或云同步。
- 不引入新依赖；若实现必须增加依赖，停止并询问。
- 不修改数据库 schema；优先复用现有 JSON 数据和任务存储。若必须迁移，停止并询问。
- 设置必须满足保存成功、GET 读回一致、刷新后仍一致、实际消费者生效。
- 不显示、保存或导出模型的私密隐藏思维链；只展示结构化阶段、模型主动返回的可公开推理摘要和生成正文。
- Open Design 只生成设计产物；业务代码按本计划串行实施。
- 每个行为变化先写失败测试，确认失败原因正确，再写最小实现。
- 不通过修改断言、增加 skip/xfail 或删除测试掩盖回归。
- 不 push 远程。

## 3. 产品决定

以下决定按用户要求和只读审计的推荐方案执行：

1. 首页主区改为“最近笔记”，与 `/notes` 共用持久化笔记投影；运行任务另设紧凑活动区。
2. 笔记可打开性由笔记是否存在决定；总结子任务失败不能把已有笔记变成不可打开。
3. 合集成为一级入口 `/collections`；旧 `/workspaces` 保留兼容重定向。
4. 任务中心第四个统计卡使用“等待中”；累计素材数放页头辅助统计。
5. `/notes` 同时收敛顶栏、多选操作栏、合集选择器和分页，不只缩短一个控件。
6. 导出默认导出当前屏幕正在显示的内容；内容来源与文件格式分两步选择。
7. “新建总结”只保留 NoteShell 顶栏一个入口；AI 工具不再重复该入口。
8. AI 工具第一批为思维导图、行动项、要点卡、闪卡/测验、术语表、时间线和选区改写。
9. 结构化 AI 产物独立保存，不伪装成总结版本；选区改写必须预览差异并接受/拒绝。
10. 问 AI 使用桌面右侧可调宽停靠面板；小屏使用底部抽屉。
11. 说话人角色使用“预设角色 + 可选自定义说明”。
12. 身份化总结主模板收敛为会议/决策、采访/Q&A、客户沟通、课堂/讲座；窄模板放“更多”。
13. 角色变化不伪装成历史总结已重写；旧版本提示身份已变化，并允许生成新版本。
14. 创建总结后只在用户未主动切换版本时自动选中新结果；以服务端返回的 `summary_id` 为准。
15. 总结语言默认简体中文；首批提供跟随原文、简体中文、繁体中文、英文、日文、韩文和自定义 BCP-47。
16. 段落对齐按用户明确要求实现；导出时保留 HTML 对齐语义，并标明 Markdown 兼容边界。
17. 推理模型只展示结构化阶段和可公开推理摘要，不持久化原始隐藏思维链。
18. Video / Image / Text 旧详情路由逐步兼容重定向到 NoteShell，停止维护第二套总结状态机。
19. NoteBi 只管理自己负责下载的模型；Ollama 等外部运行时只展示连接状态。
20. 本地模型允许移除，但需要确认；正在使用或当前启用的模型不能删除。
21. Pyannote 作为受许可约束的高级回退可见，默认使用无需账号许可的说话人路线。

合集数据行为已确认：一篇笔记可以同时归入多个合集；笔记、总结、转写和媒体只有一个 canonical 内容实体，合集只保存成员关系。编辑在所有合集入口同步；从合集删除只解除该关系，删除合集不删除笔记。

- 冻结语义 token、排版、间距、圆角、阴影、动效、焦点和响应式规则。

## 6. 强制停止条件

- 需要安装新依赖、模型或全局软件；
- 需要数据库 schema 变更或已有用户数据迁移；
- 需要删除仍有调用方的能力或用户数据；
- 发现同主题 worktree、未提交改动或另一个执行 Agent 正在改相同文件；
- 真实接口、数据结构或产品行为与本计划冲突；
- 需要处理 API key、Cookie、Token、许可或权限边界；
- 现有测试出现回归，且只能通过改断言、skip/xfail 或改变既有产品语义通过；
- Open Design 产物之间相互矛盾，无法形成唯一设计事实源。
