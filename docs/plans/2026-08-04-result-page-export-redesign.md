## 1. 目标与背景

当前结果页导出分散在多个入口（转录文本、字幕、烧录视频、总结导出、飞书/Notion 对话框），分类逻辑互相重叠。本次重构统一为**四维正交模型**：

```
导出 = 内容 × 格式 × 选项 × 目的地
```

| 维度 | 取值 |
|------|------|
| 内容 | 转写（转录文本） / 总结 / 媒体文件 |
| 格式 | 见各内容分区 |
| 选项 | 说话人开关 / 时间轴开关（仅文档格式）/ 语言（双语·仅翻译·仅原文） |
| 目的地 | 本地下载 / 飞书 / Notion / Obsidian / 其他 |

**注意**：「转写」= 音视频转录出来的**文本内容**，不是源文件。场景是视频和音频的总结结果页导出。

## 2. 已锁定决策（用户 2026-08-04 逐条确认）

| # | 决策 | 说明 |

| D5 | 说话人无数据时禁用开关 | 「带说话人」置灰 + 提示「该录音未识别到说话人」 |

## 3. 分类结构（与 SVG 图谱一致）

### 3.1 转写（转录文本）

```
格式 = 时间轴格式 [SRT, VTT, ASS]          ← 自带时间轴，无开关
     | 文档格式   [TXT, Word, Markdown]    ← 出现「带时间轴」开关（默认开）

选项（对全部格式生效）：
  说话人：开 / 关        ← 无说话人数据时禁用
  语言：双语（默认）/ 仅翻译 / 仅原文  ← 按翻译可用性回退（见 §5）
```

### 3.2 总结

```
格式 = TXT / Word / Markdown / HTML / PDF / PPT / 长图
说话人区分在总结生成时已选定 → 导出默认包含，无开关
```

### 3.3 媒体文件

```
视频 · 烧录字幕版   ← 语言三选项：双语（默认）/ 仅翻译 / 仅原文
视频 · 原始版       ← 无字幕
音频 · 仅音频文件   ← 不可烧录，字幕走「转写」
```

### 3.4 目的地

```
本地下载            ← 全格式
飞书 / Notion / Obsidian / 其他  ← 仅文本内容（转写 + 总结），媒体文件不支持云笔记
```

## 4. UI 形态（建议方案，已确认方向后可按此实现）

结果页导出入口统一为一个导出面板（抽屉或模态），**四段式布局**，从上到下：

1. **内容分区**（单选）：转写 / 总结 / 媒体文件 — 顶部 Tab 或分段控件
2. **格式选择**：随内容分区切换，chips 或列表单选
3. **选项区**：说话人开关、时间轴开关（仅文档格式）、语言三选（segmented，双语默认）
   - 禁用态规则：说话人无数据 → 说话人开关禁用；翻译缺失 → 按 §5 回退
4. **目的地**：本地下载（默认）/ 飞书 / Notion / Obsidian / 其他 — 选云笔记时媒体文件格式自动隐藏

**交互规则**：
- 语言选项切换不影响播放连续性（面板与播放器独立，不重启播放）
- 选择状态按 item 记忆（localStorage），下次打开同一条目恢复
- 文件名预览实时显示（按 D10 命名规则）
- 回退发生时给非阻断提示（如「翻译仅覆盖 60%，缺失部分将显示原文」）

## 5. 语言回退规则（翻译可用性三态）

翻译数据来源：`results.translations[target_lang]`（`workspaces.py` POST `/{workspace_id}/items/{item_id}/translate`，与转写行索引对齐）。

| 状态 | 判定 | 双语 | 仅翻译 | 仅原文 |
|------|------|------|--------|--------|
| 完全可用 | `_translation_complete = true` | 可用 | 可用 | 可用 |
| 部分缺失 | 填充率 0 < x < 1 | 可用 | 可用（缺失行回退原文并标注） | 可用 |
| 完全缺失 | 无 translations 或填充率 0 | 禁用 | 禁用 | 强制选中 |

默认选中：翻译可用时「双语」；不可用时「仅原文」。

### 6.3 命名规则（D10）


## 7. 验收标准

1. 转写四种文档格式 + 三种时间轴格式全部可导出，语言/说话人开关对全部格式生效
2. 无说话人数据时开关禁用且有提示；翻译完全缺失时仅「仅原文」可选
3. 部分翻译缺失时，缺失行回退原文且导出文件中有可辨识标注
4. 烧录字幕视频支持三种语言选项；音频条目不出现烧录入口
5. `_build_srt` 使用真实 start/end，不再生成 `t_sec+3` 的假区间
6. 文件名符合 D10 规则
7. 云笔记目的地仅出现转写+总结，无媒体文件选项
8. 现有 pytest/vitest 全绿；新增导出参数有单测覆盖（含回退三态）

## 8. 明确不做

- 批量导出（D11，UI 不出现入口）
- 媒体文件上传云笔记
- 总结导出的说话人开关（D12）
